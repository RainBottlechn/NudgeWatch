# NudgeWatch 0.8.0 · Windows x64

## 项目目的

本项目旨在集成**事务与微信提醒**、**任务编排**、**微信聊天对象管理**三个办公功能于一体，方便知识工作者便携、快速地处理日常事务与消息。

---

## 使用办法

### 1. 安装与启动
- **运行环境**：Windows 10 / 11（x64），系统自带 .NET Framework 4.8，无需额外安装运行时。
- **绿色运行**：下载 Release 中的 `NudgeWatch-0.8.0-win-x64.zip`，解压后直接双击运行 `NudgeWatch.exe`。
- **数据存储**：配置、提醒、任务与归档记录保存在 `%APPDATA%\NudgeWatch.Native`（直接兼容旧版 `0.6.x` / `0.7.x` 的 `state.json`）。
- **开机自启**：在主面板「微信」页点击「设置 ▾ → 随 Windows 登录启动」即可启用；程序移动位置或升级后会自动同步路径，并在被系统启动设置禁用时支持一键恢复。

### 2. 日常高效操作
- **全局快捷键**：
  - `Alt + N`：呼出快捕条，输入一句话即可快速创建提醒或任务，实时显示解析预览：
    - 建提醒：`15:00 评审 #避免1h @强`、`30分钟后 复核 @每天`
    - 建定时任务：`15:00 提交周报 #任务`
    - 建无定时任务：`#任务 核对昨日流水`
  - `Alt + W`：快速打开或切回主面板。
- **桌面悬浮球（推荐配合养成习惯）**：
  - **主球左键**：打开主面板；当前有微信提醒弹窗时直接跳转对应会话；微信进托盘失联时点击尝试唤醒。
  - **下方微信开关圆扣 / 鼠标中键**：一键**打开（恢复）或最小化微信窗口**，并在最小化前自动将微信会话列表回顶。建议平时通过这里开关微信，保持微信在任务栏最小化保活，避免关闭到托盘导致漏收消息。
  - **拖动贴边**：拖动悬浮球可自动吸附到屏幕左右边缘。
- **微信会话管理与同步**：
  - **右键即全部操作**：在「微信」页右键点击任意会话或分组，即可打开会话、加入/移出分组、设置提醒强度、编辑备注、导出记录或取消多选。
  - **同步更多群聊**：点击「⟳ 同步群聊」，按提示短暂暂停键鼠操作，程序会自动翻页收录新群聊，并自动保护跳过已同步或已归组的会话，不会重复同步或覆盖分组。

## 当前功能

### 一、事务与微信提醒
- **多级提醒体系（L1–L4）**：支持「忽略 / 仅记录 / 弱提醒 / 强提醒（居中弹窗）」及 L4 紧急强提示，可为单个微信会话单独设定级别，或通过关键词（如 `@我`、`紧急`）自动提级。
- **单次与周期日程**：支持单次、每天、每周、每月、每年及自定义日期周期，完成周期提醒自动推进到下一次。
- **灵活免打扰**：支持会议前后自动免打扰、顶部一键临时免打扰，以及在提醒弹窗中针对**单个会话、指定会话或全部消息**设置定时免打扰；免打扰结束后汇总未读提醒。
- **防误操作**：完成、删除或转换后提供 5 秒撤销条，面板内支持 `Ctrl + Z` 撤销。

### 二、任务编排
- **定时与无定时任务**：支持按自定义任务分组归类、一键全展/全折及复选框批量切分组、改状态、完成或删除。
- **待确认追催闭环**：任务到点或逾期后持续标记待确认；暂先收起后默认次日 `09:30` 自动追催，也可随时延后指定分钟、自定义时间、转为「进行中（停止追催）」或「暂缓」。
- **提醒与任务联动**：单次提醒可转为任务；任务可直接转为提醒，或派生关联提醒副本（完成副本后原任务仍需单独确认）。
- **状态视图与回收站**：提供「进行中 / 今日 / 已完成 / 回收站」筛选视图，回收站保留 30 天并支持随时恢复或彻底删除。

### 三、微信聊天对象管理
- **分组与快速检索**：自动展示「新消息」动态视图、自定义分组与「已收录 · 待归组」，支持按会话名、分组名、备注和常用简体字拼音首字母实时搜索，也支持手动/批量粘贴添加群名与拖拽归组。
- **已同步对象保护**：翻页同步群聊时自动过滤已归组和已收录会话，避免重复同步与误改分组。
- **精准跳转与防漂移回顶**：点击会话支持视口内直达与视口外搜索精确校验跳转（遇重名自动提示人工确认）；支持通过悬浮球按钮最小化自动回顶、微信失焦静默回顶与手动「⤒ 回顶」。
- **消息归档与导出**：自动归档实时采集的消息摘要（含免打扰期间），支持按日期、会话、分组、关键词、强提醒和 `@我` 筛选，一键复制或导出为 Markdown、CSV、TXT（默认保留 30 个自然日，可在设置中调整为 7 / 30 / 90 天或永久）。

### 四、界面与原生体验
- **7 套主题与全量控件主题化**：提供跟随系统、白天/夜晚经典及 4 套高清油画主题（莫奈睡莲、梵高星夜、维米尔珍珠、日出印象），覆盖滚动条、日历、提示气泡与深色标题栏，并遵循系统「减少动画」设置。
- **四态状态感知**：托盘图标与桌面悬浮球实时呈现正常、未读、免打扰、失联四态及微信窗口开关状态。
