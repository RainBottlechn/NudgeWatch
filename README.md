# NudgeWatch 0.8.0 · Windows x64

解压绿色包并运行 `NudgeWatch.exe`。运行环境为 .NET Framework 4.8，应用数据位于 `%APPDATA%\NudgeWatch.Native`。原生版 0.6.x / 0.7.x 的 `state.json` 可直接载入。

## 界面与主题

- 全量控件主题化：覆盖滚动条、复选框、中文日历选择器、提示气泡、深色标题栏（Windows 10/11 DWM）与主题化确认框，不再出现浅色/系统白框撕裂。
- 7 套主题（跟随系统、白天/夜晚经典、4 套油画主题）：内置 200% DPI 高清名画横幅、无缝亚麻画布底纹与带缩略图的主题选择器；统一品牌徽标并支持四态托盘图标（正常、未读、免打扰、失联）及悬浮球月牙/失联徽章。
- 主面板采用分段页签计数、筛选胶囊、结构化提醒/任务/会话行与上下文操作条；快捕条（Alt+N）支持实时解析预览；提醒弹窗按 L2/L3/L4 分级呈现，遵循系统「减少动画」设置。

## 提醒与任务

- Alt+N 打开快捕条。输入 `15:00 评审 #避免1h @强` 建提醒，输入 `15:00 提交周报 #任务` 建定时任务，输入 `#任务 核对昨日流水` 建无定时任务。Alt+W 打开主面板。
- 提醒支持单次及周期、会议免打扰和 L1–L4 分级。任务可分组，逾期或提醒后在列表中持续标记待确认。收起提醒后默认于次日 09:30 追催，也可在弹窗或编辑页指定时间。
- 右键单次提醒可转为任务。任务可直接转为提醒，也可派生一条关联提醒副本。完成副本后，原任务仍需单独确认。
- 完成、删除或转换后显示 5 秒撤销条，面板内可用 Ctrl+Z 撤销最近操作。在「已完成」或「回收站」可恢复、复制或彻底删除。回收站保留 30 天。

## 微信

- 「微信」页支持按会话名、分组、备注和常用简体字拼音首字母搜索。「分组」菜单可一次粘贴多行群名。「同步更多群聊」短暂切换到微信翻页收录，请按界面提示暂停操作。
- 视口外跳转校验微信搜索浮层中的名称、结果类型和唯一性。提示「存在重名或未精确匹配」时，可在微信浮层选定目标。
- 「列表回顶」为手动入口。微信失焦约 8 秒以及通过 NudgeWatch 最小化或跳转前，会尝试通过 UIA 静默回顶。微信 4.1.8.107 的会话列表缺少可用的后台滚动接口，本机通过琥珀色提示和手动入口处理。微信最小化时可继续采集，关闭到托盘时暂停。
- 「消息归档与导出」可按日期、会话、分组、关键词、强提醒和 @我 筛选，并复制或导出 Markdown、CSV、TXT。消息归档记录实时采集到的摘要，免打扰期间也会归档。默认保留最近 30 个自然日，包括当天。

## 构建与验收

```powershell
.\build.ps1 -Tests
.\bin\PrototypeTests.exe
.\bin\Acceptance.exe unit
.\bin\Acceptance.exe
.\bin\Acceptance.exe work-items
.\bin\Acceptance.exe archive
.\bin\Acceptance.exe viewport
.\bin\Acceptance.exe center
.\bin\Acceptance.exe cover
.\bin\Acceptance.exe live --badge
.\bin\Acceptance.exe tray
```

微信实机验收使用已登录的 4.1.8.107。测试会短暂切换焦点、滚动和搜索，`live --badge` 会在文件传输助手上做真实已读及未读切换。验收实例使用独立临时数据。分期结果随绿色包交付。
